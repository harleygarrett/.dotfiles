# Google Chrome Settings

## Disable AI Mode in Search Bar

1. Open [chrome://flags/](chrome://flags/)
2. Search for **AI Mode Omnibox entrypoint** and set as **Disabled**
3. Relaunch Google Chrome

Source: https://www.reddit.com/r/chrome/comments/1n0so6c/comment/njgpopz/

## Remove *Ask Gemini*

1. Open [chrome://flags/](chrome://flags/)
2. Search for **Glic** and set as **Disabled**
3. Relaunch Google Chrome

Source: https://www.reddit.com/r/GoogleGeminiAI/comments/1tjddwn/how_to_remove_ask_gemini_from_right_click/

## Disable *AI Innovations* Settings

1. Go to Chrome Settings
2. Search **AI Innovations** and click **Skills in Chrome**
3. Disable the **Enable skills in Chrome** setting
